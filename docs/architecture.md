# HSTA-CM 架构说明

## 输入和三路编码

输入是 `[B, 30, 3]`，三个特征为包长、方向和包间隔，隐藏维度为 256。

| 分支 | 处理 | 输出 token |
| --- | --- | ---: |
| Mamba 时序分支 | 线性投影，两个残差 Mamba 块，LayerNorm | 30 |
| 包关系图分支 | 线性投影，两层残差图消息传递，LayerNorm | 30 |
| 频谱卷积分支 | 沿 30 个包做 rFFT，拼接实部和虚部，投影后沿频率轴执行核 `1/3` 的两个残差 `Conv1d` 块，LayerNorm | 16 |

30 点实值序列的单边 rFFT 有 `30 // 2 + 1 = 16` 个频点。代码保留实部和虚部，因此没有把相位简单丢弃；频域输入形状为 `[B, 16, 6]`，再投影到 256 维。

三路来自同一个原始流量：Mamba 建模顺序和状态依赖，图分支建模包间关系，频谱卷积建模频点间的局部结构。它们提供不同归纳偏置，是否互补需要消融验证，不能称为完全独立的信息来源。DFT 沿包序号计算；包到达并非等时间间隔，频点不能直接解释为实际时间的周期频率。

频谱分支的 `1/3` 是依次执行的两个残差块，每个块执行 `x = x + block(x)`。核 1 主要混合通道，核 3 聚合相邻频点。各分支层间残差保留，输出分别进行 LayerNorm 后再融合。

## 单流包关系图

每条流的包分别为节点，节点输入来自同一个经过已知训练流量 scaler 标准化的 `[30,3]` 矩阵。图只在单条流内构建，不使用类别标签、未知来源元数据或其他流，推理时独立构图。保留两种关系并使用独立的可学习投影：

- 顺序关系：连接相邻包并加入自环。
- 相似关系：在排除自身和直接相邻包后，根据标准化输入的平方欧氏距离选取最近的 4 个有效包；距离相同时按包位置稳定排序。按 `1/(1+d²)` 加权并对称化。自环只由顺序关系提供，避免重复计算。

两种邻接矩阵分别采用标准对称归一化 `D^(-1/2) A D^(-1/2)`。两层 pre-LayerNorm 残差消息传递使用 PyTorch `bmm` 和 `Linear` 聚合两种关系，并经过非线性变换和残差相加，最后进行 LayerNorm。图结构由输入特征决定；包位置编码在图分支输出后加入，不参与最近邻距离计算。

训练入口向 HSTA-CM 传入已知训练 scaler 下的补零特征向量，用于识别有效包。补零包不参与构图、图/Mamba 分支池化或融合值计算；张量保留 30 个包位置以保持 76-token 布局。包位置编码和类型编码不会使补零节点重新成为有效输入。

## 编码和融合

Mamba 和 GNN 使用包位置编码；DFT 分支使用频率位置编码。三路分别加入 Mamba（索引 0）、GNN（索引 1）和 DFT-CNN（索引 2）的分支类型编码，拼接后得到 `[B, 76, 256]`。位置编码和类型编码均可学习；类型编码说明 token 来源，不属于位置编码。

融合层后使用一个 PyTorch FlashAttention 块。该块包含 pre-LayerNorm 自注意力、残差连接、前馈网络和第二个残差连接，CUDA 正式运行强制使用 FlashAttention 后端。最后经过 LayerNorm，按三路分别平均池化，再做等权融合和分类。

`HSTA-CM-open` 的输出为 61 类（60 个已知类加 unknown）；`HSTA-CM-closed` 的输出为 60 类。closed 没有显式 unknown 神经元，评估时只能使用 `1 - max(known probability)` 作为拒识分数。

## 消融解释

- `no_mamba`：只移除 Mamba，保留 GNN 和 DFT-CNN，共 46 个 token。
- `no_gnn`：只移除包关系图分支，保留 Mamba 和 DFT-CNN，共 46 个 token。
- `no_dft`：只移除频谱卷积分支，保留 Mamba 和 GNN，共 60 个 token。

三项正式消融均使用 256 维、相同数据、训练策略、seed 和 unknown 监督。`no_attention` 可作为后续融合模块检查，但不在当前正式运行矩阵中。当前新结构尚未训练，不能预先声称图分支替换或频谱减层提高准确率。
