# HSTA-CM 架构说明

## 输入和三路编码

输入是 `[B, 30, 3]`，三个特征为包长、方向和包间隔，隐藏维度为 256。

| 分支 | 处理 | 输出 token |
| --- | --- | ---: |
| Mamba 时序分支 | 线性投影，两个残差 Mamba 块，LayerNorm | 30 |
| 原始包卷积分支 | `Conv1d` 投影，核 `1/3/5` 的顺序残差块，LayerNorm | 30 |
| DFT 频域卷积分支 | 沿 30 个包做 rFFT，拼接实部和虚部，再沿频率轴做 `Conv1d` 顺序残差块 | 16 |

30 点实值序列的单边 rFFT 有 `30 // 2 + 1 = 16` 个频点。代码保留实部和虚部，因此没有把相位简单丢弃；频域输入形状为 `[B, 16, 6]`，再投影到 256 维。

三路来自同一个原始流量，区别是建模空间不同：Mamba 建模状态和较长依赖，原始卷积建模相邻包的局部模式，DFT 卷积建模频率结构。它们是互补表示，不能称为完全独立的信息来源。原始卷积沿包位置轴，DFT 卷积沿频率轴，两路使用独立参数。

当前 `1/3/5` 为每一路内依次执行的三个残差块：每个块执行 `x = x + block(x)`。它不是三个并行卷积分支。

## 编码和融合

Mamba 和原始包分支使用包位置编码；DFT 分支使用频率位置编码。三路分别加入 Mamba、原始卷积和 DFT 卷积的分支类型编码，拼接后得到 `[B, 76, 256]`。

融合层后使用一个 PyTorch FlashAttention 块。该块包含 pre-LayerNorm 自注意力、残差连接、前馈网络和第二个残差连接，CUDA 正式运行强制使用 FlashAttention 后端。最后经过 LayerNorm，按三路分别平均池化，再做等权融合和分类。

`HSTA-CM-open` 的输出为 61 类（60 个已知类加 unknown）；`HSTA-CM-closed` 的输出为 60 类。closed 没有显式 unknown 神经元，评估时只能使用 `1 - max(known probability)` 作为拒识分数。

## 消融解释

- `no_conv`：同时移除原始包卷积和 DFT 卷积，只保留 Mamba；只能评价卷积路径整体贡献。
- `no_mamba`：移除 Mamba，保留两条卷积路径；评价时序状态空间路径的贡献。
- `no_attention`：保留三路特征和编码，移除 FlashAttention 及其前馈子层。

现有 `no_conv` 不能单独证明 DFT 的贡献；若论文需要独立声称 DFT 有效，应另做 `no_dft` 对照，并保持数据、训练策略和 seed 不变。
