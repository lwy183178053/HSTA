# HSTA-CM 架构

## 输入和主干

每条流只取前 30 个包，三个通道依次为包长、方向和包间隔。模型输入为 `[B, 30, 3]`，所有主模型宽度固定为 `256`。PPI 已经限定 30 个包，数据文件名使用数据集和采样档即可。

HSTA-CM 的核心两条分支并行处理同一输入：

1. **空间卷积分支**：将张量转为通道优先形式后通过三层 PyTorch `Conv1d`，每层使用大小为 3 的卷积核、归一化和激活，并用投影残差连接输入与输出。该分支建模相邻包之间的局部模式。
2. **时序 Mamba 分支**：使用当前 `mamba_ssm` 提供的两层 Mamba，层间保留残差连接。该分支建模包序列的长程依赖。

两条分支投影到相同的 256 维后拼接，经融合全连接层得到注意力 token。随后将可学习的位置编码加到融合后的序列上，使注意力能够识别不同包位置。

当前 small 结构筛选在 TLS 和 QUIC 上分别选择了不同的配置。TLS 的正式配置增加第三条**频域卷积分支**：对包序列沿时间维进行实部/虚部保留的 rFFT，再经过与原始卷积分支相同的残差 `Conv1d` 提取块；频率位置编码和三种分支类型编码随 token 一起输入融合层。QUIC 的正式配置使用 Mamba、原始包多尺度 `Conv1d` 两条分支，卷积核按 `1/3/5` 逐层扩大，并启用包位置编码和两种分支类型编码。结构选择只依据 small 验证集已知类别 Macro-F1，测试集只用于最终报告。

## 注意力和输出

融合 token 进入 PyTorch `scaled_dot_product_attention` 的 FlashAttention 后端，随后执行 LayerNorm、池化和分类头。运行配置要求 CUDA FlashAttention；不在正式实验中静默回退到 CPU 或数学实现。`no_attention-open` 直接跳过注意力并保持其余层与维度一致。

开放模型的分类头为 `41` 类（40 个已知类加 `unknown`）；闭集模型为 `40` 类。开放模型在训练中使用独立的 unknown 支持流量，闭集模型和五个基线不使用 unknown 监督，测试时再用已知验证流量校准拒识阈值。

## 消融和基线

消融配置为：

- `no_conv-open`：移除卷积分支，只保留 Mamba 分支和融合/注意力部分；
- `no_mamba-open`：移除 Mamba 分支，只保留卷积分支和融合/注意力部分；
- `no_attention-open`：保留两条分支和融合层，移除 FlashAttention。

三个消融均为 256 维、41 类、seed 599，并使用同一时间划分与 unknown 来源。

保留的适配基线为 30pktTCNET、NetMamba、SRViT、TrafficAudio 和 BPF-GNN。它们接收相同 `[30, 3]` 输入和 40 个已知标签，仅保留各自的核心建模思想，不声称复现原论文的完整字节、图像、音频或旁信息管线。TrafficAudio 内部的 BiGRU 属于该基线；独立 GRU 和 Transformer 不再单独运行。

## 参数和实验口径

参数量由配置中的输入通道、隐藏宽度、Mamba 层和分类头决定，与数据采样规模无关。数据档只改变每类流量上限：`small=200/40/40`、`medium=2000/400/400`、`large=20000/4000/4000`（训练/验证/测试）。所有运行从第 1 轮开始，最多 100 轮，使用验证集已知类别 Macro-F1 调度学习率和早停，patience 为 15。
